# Working preferences

- Read the repository's guidance and follow its existing conventions.
- Make the smallest complete change. Avoid new dependencies and abstractions unless the task needs them.
- Keep unrelated local changes intact. Never commit credentials, machine-local state, or generated caches.
- Work in small, reviewable pull requests. Leave merging to me unless I explicitly ask you to merge.
- Run the relevant formatting, validation, and tests before presenting a change. State what you did not verify.
- Continue authorized work without repeatedly asking for confirmation. Ask when a missing decision materially changes the result.
- Explain outcomes and tradeoffs concisely, using plain language.
